# ISA — oko-cloud посадочная страница

## Goal

Посадочная страница oko-cloud для клиентов: UK + EN, конкурентный анализ (сайты, тарифы, цены), цены ниже конкурентов, «7 дней бесплатно» как главный крючок, дизайн уровня конкурентов вместо пустого shadcn-дефолта.

## Current state

- Маркетинг-сайт существует: TanStack Start + shadcn/ui + Paraglide (uk/en), страницы home / how-it-works / faq / contact / terms / privacy, prerender + hreflang заложены в план.
- Копирайт приличный, но дизайн — дефолтный shadcn без визуальной идентичности («пустой»).
- Страницы тарифов нет; faq_q8 говорит «пока бесплатно».
- Биллинга в продукте нет (решение 2026-07-20: MVP без оплаты) — тарифная сетка на лендинге будет витриной будущих планов.

Evidence: `docs/competitors-2026-08.md` (9 конкурентов, official pricing pages verified 2026-08-17, 3 параллельных Research-агента).

Signature-элемент: **7-дневная retention-полоса** — визуализация «7 діб завжди безкоштовно» (старые сегменты растворяются, 7 держатся), повторяется в hero-feed и тарифах. Риск: CSS-имитация камера-фида в hero может выглядеть игрушечно — держим её абстрактно-технической (mono, сетка, без фейковых фото).
