# ISA — oko-cloud посадочная страница

## Goal

Посадочная страница oko-cloud для клиентов: UK + EN, конкурентный анализ (сайты, тарифы, цены), цены ниже конкурентов, «7 дней бесплатно» как главный крючок, дизайн уровня конкурентов вместо пустого shadcn-дефолта.

## Current state

- Маркетинг-сайт существует: TanStack Start + shadcn/ui + Paraglide (uk/en), страницы home / how-it-works / faq / contact / terms / privacy, prerender + hreflang заложены в план.
- Копирайт приличный, но дизайн — дефолтный shadcn без визуальной идентичности («пустой»).
- Страницы тарифов нет; faq_q8 говорит «пока бесплатно».
- Биллинга в продукте нет (решение 2026-07-20: MVP без оплаты) — тарифная сетка на лендинге будет витриной будущих планов.

## Claims

- [x] C1. Проведён конкурентный анализ: таблица конкурентов (Украина + международные VSaaS) с тарифами, ценами, retention, бесплатными уровнями и паттернами лендингов. Evidence: `docs/competitors-2026-08.md` (9 конкурентов, official pricing pages verified 2026-08-17, 3 параллельных Research-агента).
- [x] C2. На сайте есть секция/страница тарифов на обоих языках, цены позиционированы ниже сопоставимых конкурентов, тариф Free с 7-дневным облачным архивом выделен как главный оффер. Evidence: `web/src/components/marketing/pricing.tsx` (#pricing на главной), скриншоты oko-{en,uk}-final; $2.49/$4.99 vs Partizan $5.99/$17.99 (docs/competitors-2026-08.md).
- [x] C3. Лендинг переработан по дизайн-плану frontend-design скилла: токен-система (палитра, типографика, layout, signature-элемент), не читается как shadcn-дефолт. Evidence: план в Decisions 2026-08-17; Interceptor-скриншоты до (дефолтный shadcn) и после; Fixel Display/Text loaded подтверждено document.fonts.
- [x] C4. Обе локали полные: каждый новый ключ есть в uk.json и en.json, русского контента нет. Evidence: программный diff ключей пуст (107/107), grep [ыэъё] в uk.json пуст.
- [x] C5. `bun run build` зелёный, все маршруты (en и /uk/*) рендерятся; визуальная верификация обеих локалей в реальном браузере. Evidence: build ✓, 10/10 маршрутов HTTP 200, Interceptor-скриншоты en+uk (desktop). Мобильные ширины — [DEFERRED-VERIFY], см. Log.

## Anti-claims

- A1. Не трогать ЛК/админку (_app/*) и backend — только маркетинговые поверхности.
- A2. Никакого русского языка на публичных страницах.
- A3. Не деплоить на инфраструктуру Айдара (правило: ничего нового до оплаты) без явного ОК.
- A4. Цены на лендинге не публикуются как окончательные без подтверждения Ильи — тарифная сетка сначала показывается ему.

## Decisions

- 2026-08-17: Установлен официальный скилл Anthropic `frontend-design` (из anthropics/skills) в ~/.claude/skills/frontend-design — по просьбе Ильи, для дизайн-работы.
- 2026-08-17: **Тарифы утверждены Ильёй (агрессивная сетка):** Free — 7 дней, до 2 камер / Start — 7 дней, без лимита камер, $2.49/кам/мес / Plus — 30 дней, $4.99/кам/мес. Валюта по локали: en → $, uk → ₴ (₴99 / ₴199 — округлено вниз от курса ~41.8, дешевле пересчёта). CTA платных — «написать нам» (биллинга нет), сноска честно говорит «сегодня всё бесплатно, цены — с запуска платных тарифов».
- 2026-08-17: **Дизайн-план (по frontend-design):** направление «монітор охорони при денному світлі» — светлая инженерная страница, внутри которой тёмные «feed»-компоненты мира видеонаблюдения. Палитра: paper oklch(0.985 0.002 240) / ink oklch(0.22 0.02 255) / feed oklch(0.18 0.015 255) / armed-green primary oklch(0.46 0.1 155) (цвет «під охороною» с охранных панелей) / REC-red signal oklch(0.6 0.21 25) только для micro-акцентов (REC-точка, live-бейдж), не для CTA. Типографика: Fixel Display + Fixel Text (украинский открытый шрифт MacPaw, OFL, кириллица) + IBM Plex Mono для таймстемпов. Signature-элемент: **7-дневная retention-полоса** — визуализация «7 діб завжди безкоштовно» (старые сегменты растворяются, 7 держатся), повторяется в hero-feed и тарифах. Отвергнутые AI-дефолты: cream+serif+terracotta, чёрный+кислотный акцент, broadsheet-линейки. Риск: CSS-имитация камера-фида в hero может выглядеть игрушечно — держим её абстрактно-технической (mono, сетка, без фейковых фото).
