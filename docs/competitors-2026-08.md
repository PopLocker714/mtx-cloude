## Выводы для нас

1. **Якорь рынка: 7 дней непрерывной записи BYO-камеры = $3–6/кам/мес (Украина), $5–10.5 (мир). У нас это бесплатно — ни у кого такого нет.** Ближайшее «бесплатно» — 4 часа у Camcloud и live-only у Partizan.
2. **Ось цены — retention (дни хранения)**, не фичи: 30 дней стоит нелинейно дороже (Partizan $17.99). Дешевле всех на 30 дн. — Videoloft $8.99.
3. **Прозрачная страница цен — сама по себе дифференциатор**: Ajax и EZVIZ цены прячут, Eagle Eye и Videoloft — за дилерами.
4. **№1 сообщение категории: «работает с вашими камерами, без DVR/NVR»** — важнее AI. Наш лендинг уже так написан; усилить.
5. Уязвимый шов Partizan: дешёвый тариф ограничен разрешением D1. Мы без ограничения разрешения — прямой удар.

## Паттерны лендингов (шаблон категории)

- Hero: заголовок = категория + исход («Хмарне відеоспостереження…»), подзаголовок = совместимость («будь-яка RTSP/ONVIF камера»), визуал = **скриншот дашборда с сеткой камер** (стандарт B2B; у нас его нет — сделать).
- Порядок секций: hero → 3 value-карты → стена логотипов поддерживаемых брендов камер (заменяет клиентские логотипы) → фичи → «как это работает» в 3 шага → **тарифы на главной** → отзывы → FAQ → финальный CTA.
- Trust у молодых сервисов: количество камер/подключений, сертификация инфраструктуры (AWS SOC 2 / ISO 27001 — заимствованная), гарантия возврата; клиентских логотипов ни у кого из мелких нет.
- CTA: trial-first («Get a free trial» / «Start cloud recording»); никто не пишет «no credit card» — можно взять из общего SaaS.
